- **23/35** have a matching object call. Only **12/35** callsites' frame-size push values match Ghidra; the other object calls lack the expected immediate frame-size push or have a different entry sequence.

- **10/35** object calls occur after the expected two pushes at the function's entry. This is a shape check only; it does not prove all surrounding instructions, unwind behavior, table contents, or the rest of each function.
